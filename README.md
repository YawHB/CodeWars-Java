# Codewars Java Practice

Hi there :) 

Welcome to my coding challenge adventure!

I surely enjoy a good challenge. Especially when it involves programming. They give my logical thinking a workout and help me become a better problem solver.
I thought it would be awesome to document my progress publicly. That way, I (and everyone interested) can get a peek into how I'm thinking and how i'm progressing over time. 

This repository collects my Java solutions, grouped into the `kata_08` through `kata_04` folders. Each challenge title links to its solution in this project, and the Codewars link opens the original challenge page. The kata summaries below describe the challenges in a recaped format getting you up to speed quickly.

## Kata 08

### [Create Phone Number](kata_08/CreatePhoneNumber.java)

**Codewars:** [Create Phone Number](https://www.codewars.com/kata/525f50e3b73515a6db000b83)  
Given ten digits, format them as a phone number in the expected `(123) 456-7890` layout.

### [Friend or Foe?](kata_08/FilterFriends.java)

**Codewars:** [Friend or Foe?](https://www.codewars.com/kata/55b42574ff091733d900002f)  
From a list of names, keep only the ones with exactly four characters.

### [Stop gninnipS My sdroW!](kata_08/SpinWords.java)

**Codewars:** [Stop gninnipS My sdroW!](https://www.codewars.com/kata/5264d2b162488dc400000001)  
Reverse each word that has five or more letters while leaving shorter words in place.

### [Disemvowel Trolls](kata_08/Trolls.java)

**Codewars:** [Disemvowel Trolls](https://www.codewars.com/kata/52fba66badcd10859f00097e)  
Remove the vowels `a`, `e`, `i`, `o`, and `u` from a string, regardless of case.

### [Validate a PIN code](kata_08/ValidatePINCode.java)

**Codewars:** [Validate a PIN code](https://www.codewars.com/kata/55f8a9c06c018a0d6e000132)  
Check whether a string is made up of exactly four or six digits, with no other characters.
